# LocalWP Installation Guide for Cachi Studio

## Step-by-Step: Install WordPress Using LocalWP

LocalWP is the easiest way to run WordPress locally on Windows. It handles PHP, MySQL, and Nginx automatically.

### Before You Begin
- **Windows PowerShell** is available (you've been using it)
- **Administrator privileges** recommended for LocalWP installation
- **Internet connection** required for download

### Step 1: Download LocalWP
1. Open your web browser and go to: **https://localwp.com**
2. Click the **Download for Windows** button
3. Save the file to yourDownloads folder
4. **Run the installer** (double-click the downloaded file)
5. Follow the Setup Wizard:
   - Accept the license agreement
   - Choose the install location (or use default: `C:\Users\%your-user%\Local\LocalWP`)
   - Click **Install**
   - Wait for the progress bar to complete
   - Click **Finish**

### Step 2: Launch LocalWP
1. Open **LocalWP** from your Start menu or desktop
2. The LocalWP dashboard window will open
3. If prompted to sign in, you can:
   - **Skip** (or create a free account if you want cloud sync)
   - **Continue without signing in**

### Step 3: Create a New WordPress Site
1. In the LocalWP dashboard, click **"+ Create a New Site"**
2. **Site Name**: `cachi-studio` (or your preferred name)
3. **Environment**:
   - PHP: `8.1` (recommended) or `8.0`
   - Web Server: `Nginx` (recommended) or `Apache`
   - Click **Continue**
4. **Wait for the setup to complete** (takes 2-5 minutes)
   - LocalWP will automatically:
     - Install WordPress
     - Create a MySQL database
     - Configure PHP and web server
     - Set up SSL (localhost SSL)

### Step 4: Log Into WordPress
1. Once the site status changes to **"Online"**, click the **“Admin”** button
2. **OR** manually visit: `http://cachi-studio.test/wp-admin/`
   *(`.test` is a local domain suffix)*
3. **Login Credentials** (automatically generated by LocalWP):
   - **Username**: `admin` (or shown on the site card)
   - **Password**: automatically generated (shown on the site card or in the details)
   - **Password can** be changed after login

### Step 5: Access the WordPress Dashboard
1. You're now logged into WordPress!
2. The dashboard is at: `http://cachi-studio.test/wp-admin/`
3. **Bookmark** this URL for easy access
4. **Welcome to WordPress!** Let's set up the Cachi Studio theme.

### Troubleshooting During Installation

**1. "Are you sure you want to do this?" error**
- **Cause**: WordPress security check
- **Fix**: Click "Return to Roque's Home" or "Confirm" / "Yes, I'm sure"

**2. White screen after activating theme**
- **Cause**: PHP version incompatible or file corruption
- **Fix**: 
  - Ensure PHP 7.4+ (PHP 8.1 recommended)
  - Re-upload the theme files
  - Check `wp-config.php` for any syntax errors

**3. Projects not showing on Work page**
- **Fix**:
  - Go to Settings → Permalinks → Save Changes (regenerates rules)
  - Ensure each project has "Published" status
  - Ensure each project has a Project Category assigned
  - Check that the archive-project.php template is in the theme folder

**4. Contact form submits but no email received**
- **Fix**:
  - This is normal for email mode on some servers
  - Go to Customizer → Cachi Studio Settings → Form Endpoint
  - Or contact your hosting about mail() function support
  - Or configure a Formspree endpoint

**5. Custom fields not visible**
- **Fix**:
  - Top right of admin page: Click "Screen Options" tab
  - Check "Custom Fields" box
  - Refresh the page

**6. Mobile menu not opening**
- **Fix**:
  - Click the "MENU" button (top right, hidden on desktop)
  - If still not working, check for JavaScript errors: F12 → Console
  - Try disabling other plugins one by one
